# Levitate disability-led FX — plan (study)

## Goal, in one line
Test, in 90 days, whether a disability-led participation layer lifts
return and onboarding — with a grant lane and a bank lane kept separate,
and a bank-API route that is fail-closed by country.

## The three lanes, never merged
1. **Adoption lane:** creators + orgs + sessions; metrics are onboarding
   completion, mode chosen, return rate, organiser time saved. Never
   diagnoses, never medical detail, never public disability disclosure.
2. **Platform lane:** pick ONE door first — Zoom proof-of-value OR
   Microsoft for Startups. Different substrate, different SDK/Store path,
   different success metric. No merged bid or budget.
3. **Grant + bank lane:** a grant funds; a bank API (if verified, via a
   regulated partner, with consent) moves money. Neither creates the other.
   Sponsor firewall: sponsors never decide eligibility.

## 90 days
- **Days 1–30:** pick one platform, confirm SDK/Store path, write the
  data-minimisation note, recruit 3 disability-led creators + 1–3 orgs,
  record a real session on existing tools.
- **Days 31–60:** recurring sessions, not one spike; log the four metrics;
  holography off unless the venue is already booked.
- **Days 61–90:** scorecard + privacy report + accessibility notes;
  go/no-go: Marketplace/Store beta, or stop and keep selling physical displays.

## Go / no-go rule
GO only if: adoption claim allowed AND grant reporting allowed
(review signoff) AND platform gate passed. Otherwise STOP_OR_REDESIGN,
with reasons listed. No partial go.

## Grant by country — what to check before any disbursement
- Canada–NB: phase status at disbursement date, regulated partner identity,
  local grant program rules, PIPEDA scope.
- Morocco: open-banking status, CNDP guidance, local grant rules,
  local legal check; default no API payment, no NFT.
- Other: every field in the template, sourced, before any API route is used.

## What this study does NOT do
No partnership outreach, no grant submission, no bank onboarding, no
Marketplace listing, no medical claim, no revenue figure, no user count.
Those need their own approvals, partners, and evidence — none are in this study.
